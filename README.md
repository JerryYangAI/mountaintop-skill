# 山顶法则 · Mountaintop

> "你可以站在山顶——那里闪电会击中你；你不必躲在安全的山谷里。"
> —— Richard W. Hamming, *You and Your Research*, 1986

一个用于**重大选择**的噪声过滤器，做成 Agent Skill。

它不给你建议，它审问你。把正在纠结的选择丢进去，它用五道关卡逐一判定，最后指出你真正在回避的那个问题。

框架提炼自汉明 1986 年在贝尔实验室的那场演讲——那场演讲在问一件事：**同样聪明、同样勤奋的一群人，为什么只有极少数做出了留得下来的东西？**

---

## 什么时候用

- 在几个方向之间摇摆，每个看起来都不错
- 不知道该把主要精力押在哪
- 判断某个机会 / 项目 / 岗位值不值得做
- 感觉自己很忙、很努力、但没有进展
- 要做一个不可逆的取舍（离职、关停、all in、拒绝一个机会）

**不适用**：日常小决定、纯信息查询、需要专业意见的法律 / 医疗 / 财务问题。

## 安装

**Claude Code / Cowork**

```bash
git clone https://github.com/JerryYangAI/mountaintop-skill.git
mkdir -p ~/.claude/skills/mountaintop
cp mountaintop-skill/SKILL.md ~/.claude/skills/mountaintop/
```

项目级安装把 `~/.claude/skills/` 换成项目里的 `.claude/skills/` 即可。

**其他 Agent 平台**

`SKILL.md` 是纯 Markdown，frontmatter 只用了 `name` 和 `description` 两个标准字段。任何支持 skill / instruction 注入的平台都能直接用；不支持的，把正文当 system prompt 贴进去也成立。

**不用任何工具**

底下那五关的问题清单，打印出来对着自己问一遍，效果是一样的。**框架不挑载体，挑的是你愿不愿意诚实回答。**

## 怎么用

```
/mountaintop 我在 A、B、C 三个方向之间选不出来
```

或者直接说人话：

```
我手上有四个项目都在推进，但感觉哪个都没做透，帮我用山顶法则过一遍
```

它会先分诊——**可逆的小决定直接打发走**（对小事过度审慎本身就是噪声），不可逆的才走完整五关。

## 五道关卡

每关必须出 **过 / 不过 / 数据不足** 的硬判定，不许打分含糊。

### 第一关 · 测海拔

**重要 ≠ 后果大。重要 = 后果大 且 你有一个合理的进攻方案。**

时间旅行、反重力后果巨大，但不是重要问题，因为无从下手。

| | 有进攻方案 | 没有进攻方案 |
|---|---|---|
| **后果大** | ✅ 山顶 | ❌ 反重力 |
| **后果小** | ⚠️ 安全山谷 | ❌ 不必讨论 |

- **反重力**：看起来最像雄心壮志，永远不会被证伪，可以舒服地待十年
- **安全山谷**：最难自察，因为它每天都有正反馈——有产出、有收入、有人夸

> 你所在领域最重要的问题是什么？为什么你没有在做它？

### 第二关 · 验绳索

三个条件，缺一条就退回"反重力"：

1. 第一步是**具体的**（说得出下周一干什么）
2. 第一步**有反馈**（做完能判断对错）
3. **没有偷偷换小**（发现大问题没抓手，就悄悄换成自己会做的小问题，继续叫原来的名字）

再加两问：**为什么是现在？为什么是你？**

### 第三关 · 查复利

> "两个能力相当的人，一个多干 10%，产出会超过另一个两倍以上。" —— 博德

关键：那 10% 不是加在产出上，是加在增长率上。

- 买的是**能力**还是**产出**？（做完会留下下次能直接用的东西吗？）
- 新知识**挂钩**了吗？（知识是加法，连接才是乘法）
- **方向**对吗？
- 那额外的 10% **从哪减出来**？（说不出来，这一关不过）

### 第四关 · 占中心

沉浸和开门是正交的，不是对立的：

|  | 沉浸 | 不沉浸 |
|---|---|---|
| **开门** | ✅ 唯一那条路 | 什么都知道，什么都不深 |
| **关门** | ❌ 把略微错误的问题挖得极深 | — |

- **让潜意识保持饥饿**——关键动作是清空，不是加倍
- 杀死潜意识的不是被打断，是**并行的第二个重要问题**
- 情感投入测试：**没人付钱、没人看，你洗澡时也会想起来吗？**
- 开门 ≠ 社交，防"声音吸收器"

判定：现在有几件事在抢中心？超过一件，不过。

产出通常是**重新分类**（现金流类降级为执行 / 押注类只留一个），不是砍掉。

### 第五关 · 审借口

前四关是分析，这一关是审问。**卡住你的东西，基本都在这里。**

- **借口的可敬度审计**——人不会用难听的理由挡住自己，会用最体面的那个。每个"我还需要先……"都要一个**数字**和一个**日期**
- **把天赋当解释**——唯一一个既能解释现实、又能立刻让人免责的解释
- **恐惧对准了吗**——分散不是对冲，它把可逆有信号的风险，换成了不可逆无信号的风险
- **探索还是回避**——探索必须有截止日期和决策规则，否则它只是把选择无限期推迟
- **该不该打这场仗**——你想做改变体制的人，还是做一流工作的人？

## 两条硬性约束

写进 skill 里的，不是可选项：

**不煽动殉道。** 汉明本人的账单是溃疡和忽略家人，他自己承认过。目标是一件一流的作品，不是自我毁灭——集中注意力和把自己搞垮是两回事。

**这是决策框架，不是心理咨询。** 如果对话露出真正的困境是情绪或健康层面的，它会退出框架、好好说话。第五关的追问强度只适用于一个状态稳定、主动要求被追问的人。
